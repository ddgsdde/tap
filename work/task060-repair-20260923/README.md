## 修复方式和边界

用之前已经完整验证的 117 门电路作为逻辑来源，替换错误候选中与输出位 4 有关的逻辑，复用真值表相同的现有信号，再删除无用节点、合并相同 NAND，并简化输出位 0。

这不是对一个输入值加软件特判，网表仍然只有 NAND。它也**不是新的更优架构**：修复版内部信号的真值函数集合与之前正确的 117 门版本相同。网表字节不同主要来自连线选择和节点排序。修复正确性不能作为成功找到 116 门有效解的证据。
