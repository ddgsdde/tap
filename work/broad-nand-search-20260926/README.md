## 新的最低深度证明

令 `S_0={0,1,x0,x1,x2,x3}`，递推 `S_(d+1)=S_d ∪ {NAND(a,b):a,b∈S_d}`。归纳可知 `S_d` 恰为深度至多 d 的所有四输入 NAND2 布尔函数，不限制门数、共享和扇出，也允许同一信号接两个 NAND 输入。

深度上限 0、1、2、3、4 的可实现函数数分别为 **6、16、79、1,001、10,664**。Python 与 C++ 独立实现得到相同集合。

57 题输出位 0、1、3、5、6 不在 `S_4`；90 题输出位 3、5、6、9、10 不在 `S_4`。所以两题均不可能在 4 层或更浅实现，无论增加多少门。冻结链上电路提供经过全输入复核的 5 层见证，所以最低深度恰为 5。

在 5 层路线下，57 题需要 ≤36 门（≤4,500），90 题需要 ≤40 门（≤5,000）才能超过此快照。更深但大幅少门的低成本电路仍未被排除。
