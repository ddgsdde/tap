## 复现

在本目录执行：

```bash
python3 reproduce_timing.py
```

该脚本只依赖 Python 标准库，先检查 117 门输入检查点的原始字节 SHA-256，再确定性构造 118 门版本，并对两个电路分别枚举全部 256 组输入。输出 `reproduced_timing_118.json`。脚本明确标记试验版本的总成本更高。

在仓库根目录，还可以使用上轮的独立验证器：

```bash
python3 work/task060-mul4-20260923/verify.py \
  work/task060-cost-depth-20260923/best_valid_117.json
python3 work/task060-mul4-20260923/verify.py \
  work/task060-cost-depth-20260923/timing_118_NOT_COST_IMPROVEMENT.json
```

本轮对话的实验 ZIP 包包含完整搜索源码、原始日志、输入和逐项验证结果；仓库目录保存检查点、复现脚本和精简报告 `SUMMARY.json`。没有改写 `data/latest` 或之前的工作目录。

## 实验包中的搜索入口

```bash
g++ -O3 -std=c++17 cross_donor_walk.cpp -o cross_donor_walk
python3 verify.py best_valid_117.json --pairs-out start.pairs
python3 verify.py behemoth_source.json --pairs-out behemoth.pairs
./cross_donor_walk start.pairs continued 600 6100 1 behemoth.pairs
```

模式 `0` 为面积搜索，模式 `1` 为时序启发式搜索。时序模式不是全局 7 层 SAT 穷举。只有总成本确实低于当前基线的网表才会更新 `.best.pairs`；`.timing.pairs` 可能有更高成本，必须独立核验。

`depth_antichain.cpp`、`depth_guided.cpp` 是带显式前沿上限的深度搜索；`sat_ordered.py` 是带深度排序对称性约束的增量局部综合。SAT 依赖系统 `libz3`，不需要 z3py；C++ 搜索不依赖第三方库。
