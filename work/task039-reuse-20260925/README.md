## 验证不是抽样通过

输入低 16 位为 A，高 16 位为 B；常量 0/1 和输入均为深度零，最后 17 个物理 NAND 按低位到高位作为输出。直接比较 17 位无符号整数 A+B。

两种形式检查分别使用规范化 ROBDD 和 Z3 位向量算术差异模型。前者检查精确布尔函数相等，后者寻找任意输出不等于 A+B 的输入。差异模型返回 UNSAT 表示不存在反例，符号覆盖全部 `2^32 = 4,294,967,296` 组输入，并非声称逐组运行了 42.95 亿次标量仿真。

原榜首、Behemoth 来源、cin=0 专门化版本和受限模型的 248 门自测见证都通过了两套检查。另对每个审计电路运行 10,065 个确定性随机 / 进位边界向量作为补充。故意把输出位 0 改坏的负对照被两种形式检查拒绝；标量反例为 A=0、B=0，期望 0、实际 1。详情见实验包中的 `verification_report.json`。

## 本轮实际搜索

执行了单门重接、最多三 NAND 的有上限表达式模板、跨电路函数嫁接、局部切割综合、多输出联合窗口综合、带暂时加门余量的中性搜索，以及进位分组 / 进位选择的函数库映射。

单输出局部 SAT 共 1,952 次查询，多输出窗口 SAT 共 1,057 次。合计 **3,009 次受限局部查询：2,958 次 UNSAT，51 次 unknown，未得到有效刷新**。局部 UNSAT 仅适用于给定叶节点、边界函数、可达赋值、门数和深度约束，不是全局 247 门无解证明。

跨来源函数嫁接试验为 3,386 + 8,610 次；函数库映射尝试 1,140 次，其中提取出 1,080 个候选，其余 60 次为当前库内的 10 层提取失败。另测试 1,919 组联合根节点，并接受 565 个正确的中性 / 近中性搜索状态。计数允许重复，不是不同电路空间的穷尽枚举。

扩展函数库的共享逻辑选择模型允许最多 8 个新中间函数，247 门 / 11 层查询返回 unknown。不能据此判定无解。

## 一个有用但严格受限的排除结果

将中间布尔函数限制为原榜首已有的 248 个非输入函数，加 32 个输入和 0/1 常量，总计 282 个函数。枚举所有 **39,903 个无序 NAND 输入对（包含相同输入）**，得到 **877 个能留在该函数库内的 NAND 实现选择**，再联合选择无环结构。

| 模型 | 结果 |
|---|---|
| 原函数库，248 门 / 11 层 | SAT；见证通过两套算术等价检查 |
| 原函数库，247 门 / 11 层 | UNSAT |
| 原函数库，允许全部函数与输出副本，10 层 | UNSAT |

还做了更宽松的交叉检查：完全不计重复输出副本成本，只计所用非输入函数数，247 函数 / 11 层仍 UNSAT；允许全部 248 个非输入函数时，10 层仍 UNSAT。这避免把对输出门复用的额外限制误当成下降一门或一层的理由。

**这不是整个 NAND 电路空间的最优性证明。** 新的中间函数被明确排除；在 11 层内继续省门或降到 10 层，需要越出这个旧函数库。改变连线而产生新函数的电路也属于库外，本结论不排除它们。求解器 UNSAT 没有另附独立核验的 DRAT 证书。

## 复现

需要 Python 3 和系统 `libz3` 共享库，不需要 z3py。原运行环境为 Python 3.13.5、libz3 4.13.3.0。

在本目录运行只读验证：

```bash
python3 verify39.py tapeout_16160.json
```

`restricted_basis.py` 写入仓库时被连接器检查拦截，没有通过其他接口重试写入。该脚本和完整源码已保存在对话的实验 ZIP 中。以下命令在解压实验包后运行，用于复现受限函数库模型、正对照和放宽输出计数的检查：

```bash
python3 restricted_basis.py --input tapeout_16160.json --output-dir reproduced_basis
python3 verify39.py reproduced_basis/basis_selftest248.witness.json
```

受限模型程序会生成 SMT-LIB 文件、JSON 报告和正确的 248 门自测见证。后者与榜首成本相同，不是刷新结果。验证器遇到 SAT、unknown 或错误网表时返回非零退出码。

本仓库目录保留冻结基线、核心验证程序及结果摘要。对话中的完整实验 ZIP 另外包含广域搜索源码、四份来源副本、全部原始搜索日志和审计结果。实验包中的 `side38.embedded.json` 是 32 输入研究嵌入，不可直接当成原 16 输入第 38 题提交。
